## Decisions made this session

- **Stack:** React Native + Expo + TypeScript (rejected Flutter for code-sharing reasons; rejected pure Kotlin because iOS is in scope within 12 months).
- **Repo:** monorepo with pnpm workspaces + Turborepo (`apps/web`, `apps/mobile`, `packages/shared`).
- **Backend:** the Next.js `/api/*` routes serve both apps. No separate mobile backend.
- **v1 scope:** full feature parity with web at launch (user explicit choice).
- **Phasing:** 6 phases over ~6 months; Phase 0 (foundation) detailed, others outlined.
- **Mobile-side billing:** Google Play Billing on Android (mandatory for digital subscriptions per Google policy). DodoPayments stays on web. Single source of truth in Supabase `subscriptions` table.
- **Styling:** NativeWind v4 (Tailwind for RN) — keeps `className` strings reusable from web.
- **Codex audit branch:** parked on its own branch, not merged. Master has parallel improvements that overlap, so reconciliation isn't worth the time right now.
